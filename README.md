# Formulario de registro

Formulario de inscripción a un taller de programación, con campos especializados y validación integrada del navegador. Es el proyecto 4 de mi ruta de 100 proyectos de desarrollo web.

## Tecnologías
- HTML5 semántico
- CSS

## Lo que aprendí
- Estructura de un formulario con `form`, `label` e `input`
- Conectar etiquetas y campos con `for` e `id` para hacerlos accesibles
- La diferencia entre `id` (dentro de la página) y `name` (el dato que se envía)
- Tipos de campo: texto, correo, teléfono, fecha, número, URL y contraseña
- Listas desplegables (`select`), botones de opción (radio), casillas (checkbox) y `textarea`
- Agrupar campos con `fieldset` y `legend`
- Validación del navegador con `required`, `minlength`, `maxlength`, `pattern`, `min` y `max`
- Expresiones regulares básicas en el atributo `pattern`
- Por qué la validación del navegador no sustituye a la del servidor
- Por qué las contraseñas nunca deben enviarse con `method="get"`
- Estilos de formulario con `display: block`, `box-sizing` y las pseudo-clases `:focus` y `:user-invalid`

## Cómo verlo
Descarga el repositorio y abre `index.html` en tu navegador.
